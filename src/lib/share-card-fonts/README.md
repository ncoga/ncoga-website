# Share-card fonts

`dm-sans-latin.ttf` and `newsreader-latin.ttf` are static weight-600 instances of the Latin subsets in [`public/fonts/ncoga`](../../../public/fonts/ncoga). Open Graph cards use them because `ImageResponse` accepts TTF, OTF, and WOFF, does not accept the site’s WOFF2 files, and cannot parse those variable fonts.

Both families remain under the SIL Open Font License 1.1. The license texts are [`OFL-DM-Sans.txt`](../../../public/fonts/ncoga/OFL-DM-Sans.txt) and [`OFL-Newsreader.txt`](../../../public/fonts/ncoga/OFL-Newsreader.txt).
