How will event information be checked?

Each listing needs a verified date, time zone, location, organizer, registration URL, and current publication status before it appears as an upcoming event.

What happens when an event passes?

The production experience should move past events out of the upcoming list based on their time zone aware end timestamp, while retaining an archive when useful.
